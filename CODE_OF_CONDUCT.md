# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, assume good faith, and keep discussion about the work. Harassment,
discrimination and personal attacks are not tolerated.

Report problems privately through GitHub's *Security → Report a vulnerability* channel or by contacting the
maintainer through the GitHub profile. The maintainer may remove comments, issues or contributions that violate this
code and may block repeat offenders.
